Hello, this was a small project I was working on that combines OOP, CSV and pandas.
This program allows you to book a seat ._. from rows A-E and columns 1-8, 40 seats in total.
This can be modified to fit any size of seating arrangements, just import your own csv; however do make sure that the format is letters as row headers and numbers as column headers. If you do wish to change this, change the regular expression in the validate method in the class.
